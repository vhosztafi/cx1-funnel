# Motor Trade Journey and Navigation Model

This document is a repository-only, legacy-read-only specification. The mounted legacy application source is evidence and is not modified. No live funnel, environment value, browser/session content, database row, or external behavior is used to fill gaps. Commercial Combined is included only as neighboring root-page context; its funnel, API contracts, quotation/results, referral outcomes, checkout, and payments are excluded.

## Evidence Authority and Phase Depth

Mounted React controls every journey claim. Each material row has exactly one of the Phase 1 evidence statuses below and at least one repository-relative `path:symbol` citation:

- **Direct React** — behavior is stated by a mounted React component, route, manager, store, or code-referenced translation.
- **Dependency-resolved** — a named mounted React consumer leads to a supporting repository source that resolves a front-end-visible fact.
- **Conflict** — controlling React and supporting evidence disagree; React remains controlling and the conflict is linked to the clarification register.
- **Unresolved** — repository evidence proves the boundary or ambiguity but not the missing value or outcome; the known contract remains usable.

Route declaration proves addressability, not reachability. Cross-step reachability comes from `CleggGifford.CoverX.UI/src/managers/MotorTradeManager.tsx:useMotorTradeManager`, while route-local Step 6 and Step 8 views come from their mounted component handlers. Stable `MTS-*` and `EDGE-*` identifiers are documentation labels only; they do not add routes or alter displayed numbering.

Phase 2 records visible surface purpose, high-level answer groups, entry/exit structure, and guards needed to reproduce navigation. Phase 3 owns exact questions, option labels and values, messages, validation, and transformations. Dynamic labels absent from the repository are never guessed. The in-scope journey stops at the first excluded transport invocation reached after a validated Step 14 Submit (`CleggGifford.CoverX.UI/src/steps/MotorTrade/StepSummary.tsx:onSubmit`).

Where role context matters, the exact sources are `CleggGifford.CoverX.UI/src/components/ui/MotorTrade/Header.tsx:Header`, `CleggGifford.CoverX.UI/src/components/ui/MotorTrade/BrokerRibbon.tsx:BrokerRibbon`, `CleggGifford.CoverX.UI/src/components/ui/MotorTrade/MTBackofficeRibbon.tsx:MTBackOfficeRibbon`, and `CleggGifford.CoverX.UI/src/steps/MotorTrade/index.tsx:MotorTradePopulate`. Sharing a wrapper is not evidence that broker and back-office ribbons are equivalent; any referrer- or persisted-state-dependent mapping remains limited to what those sources state.

## Executable Transition Ledger

Standard manager Next and Previous call `window.scrollTo({ top: 0 })` before resolving a destination and record that destination with `setStep`. Internal Step 6/8 navigations do not change the persisted numbered step unless the row explicitly says so. `none` means that the source passes no route-state object.

The Step 9 inclusion guard is copied from mounted React without a human-readable label: resolve the selected `coverIndemnityLimitOwnVehiclesID` in `options.indemnityOwnVehicles`, then require `coverLevelID === 1`, resolved `numericValue` truthy, and `numericValue <= 15000`. The complementary branch is `otherwise`. CLR-001 remains the non-blocking source gap for the absent database-backed labels.

## State Retention, Reset, and Loss Contract

This contract describes operations proved by static repository code, not the contents of any live browser session. **Pending** means the current React Hook Form or route-local value has not yet been written through the relevant store action; **persisted** means the raw value is already held by a session-backed store or named session cache. A rendered or terminal projection can omit a raw persisted value without clearing that value. Route-local `location.state` selects an internal view for the current navigation entry and is not part of the persisted Motor Trade form.

## Route Entry and Guard Contract

The [Executable Transition Ledger](#executable-transition-ledger) is the sole canonical owner of every entry, guard, and dashboard edge. This section is a reading guide only and does not redefine those records:

- Use `EDGE-ROOT` for the root product link.
- Use `EDGE-ENTRY-CLONE`, `EDGE-ENTRY-CLIENT`, `EDGE-ENTRY-GUID-BO`, `EDGE-ENTRY-GUID-NON-BO`, and `EDGE-ENTRY-NEW` for the mutually exclusive population paths.
- Use `EDGE-GUARD-AUTH`, `EDGE-GUARD-STEP1`, `EDGE-GUARD-STEP1-UNMAPPED`, and `EDGE-GUARD-PERSISTED` for routed-surface guards.
- Use `EDGE-DASHBOARD` for the ribbon exit.

For each ID, take its trigger, condition, destination, state writes, route state, evidence status, repository evidence, and clarification exclusively from its ledger row. In particular, the auth-key check remains a presence guard rather than proof of identity or authorization, and no runtime referrer, storage value, or environment assignment was inspected. The cross-edge URL-family observations below supplement those canonical rows without changing them.

`MotorTradeBuyRouter` selects one complete href family by checking the current URL in this exact priority: S2+RTL (`motortrade-roadrisks-s2-rtl`), RTL (`motortrade-roadrisks-rtl`), S2 (`motortrade-roadrisks-s2`), then standard `MotorTradeBuyLinks`. Every href in those selected families is a direct `/motortrade-roadrisks.../steps/...` URL. The route controller's ordinary guard corrections and the manager's ordinary Next/Previous movement use those direct selected-family hrefs, so they do not retain a current `/broker/buy`, `/back-office/buy`, or new-quote context prefix. This prefix-dropping transition is the mounted contract, not a route repair (`CleggGifford.CoverX.UI/src/router/motorTradeBuyRouter.tsx:MotorTradeBuyRouter`; `CleggGifford.CoverX.UI/src/enums/motorTradeBuySteps.ts:MotorTradeBuyLinks`; `CleggGifford.CoverX.UI/src/enums/motorTradeTestSteps.ts:MotorTradeS2,MotorTradeRTL,MotorTradeS2RTL`).

`RouterEnum.MOTOR_TRADE` plus `RouterEnum.MOTOR_TRADE_BUY` declares the separate `/motortrade/buy/:step` alias. That URL contains none of the S2+RTL, RTL, or S2 family substrings, so `MotorTradeBuyRouter` falls through to standard `MotorTradeBuyLinks`; the next ordinary manager or guard navigation therefore uses the standard `/motortrade-roadrisks/steps/...` family (`CleggGifford.CoverX.UI/src/router/base.ts:RouterEnum`; `CleggGifford.CoverX.UI/src/App.tsx:App`; `CleggGifford.CoverX.UI/src/router/motorTradeBuyRouter.tsx:MotorTradeBuyRouter`; `CleggGifford.CoverX.UI/src/enums/motorTradeBuySteps.ts:MotorTradeBuyLinks`).

Summary edit is a further variant change: the call sites for Steps 1–5, 7, and 9–13 pass hard-coded standard-family `MotorTradeBuyLinks` hrefs. The source therefore permits an S2, RTL, or S2+RTL summary edit to drop its URL-family prefix; this is preserved rather than corrected (`CleggGifford.CoverX.UI/src/steps/MotorTrade/StepSummary.tsx:goToStepForEdit`).

The literal stored-step counter source is `motorTradeFormStore().step`, not the `:step` string and not a count of actually visited surfaces (`CleggGifford.CoverX.UI/src/steps/MotorTrade/MotorTradeBuyRouteController.tsx:MotorTradeBuyRouteController`). No code-evidenced Motor Trade `popstate`, `beforeunload`, `unload`, or custom browser-history handler was discovered in the mounted journey evidence. Consequently this specification defines only the explicit React Router navigations above; it makes no browser Back/Forward, refresh, or history-stack promise.

## Progress and Step Numbering Contract

The mounted text counter and Header progress bar are independent contracts. They use the same persisted numeric `step`, but they do not share a denominator rule and must not be reconciled into one derived presentation.

### Text counter

The route controller's visible contract is exactly `Step {motorTradeFormStore().step} of 14`. Its implementation reads `motorTradeFormStore().step` into `stepIndex` and renders `Step {stepIndex} of 14`; neither the URL parameter nor the set of surfaces actually visited changes the literal denominator (`CleggGifford.CoverX.UI/src/steps/MotorTrade/MotorTradeBuyRouteController.tsx:MotorTradeBuyRouteController`).

MTS-09 is conditional but retains its internal number. When the MTS-08 branch skips MTS-09 and writes persisted step 10, MTS-10 displays `Step 10 of 14`. The display remains Step 10, and this text counter keeps its visible denominator of 14.

### Progress bar

`Header` derives `totalNumberOfSteps` as 13 only when all three of these expressions are true:

1. `(coverLevelID === 1 || coverLevelID === 3)`
2. `coverIndemnityLimitOwnVehiclesID <= 6`
3. `step > 8`

Otherwise `totalNumberOfSteps` is 14. The value passed to the React Bootstrap `ProgressBar` is exactly `Math.round((step / totalNumberOfSteps) * 100)` (`CleggGifford.CoverX.UI/src/components/ui/MotorTrade/Header.tsx:Header`). This can change the bar denominator only after persisted step 8; it does not change the text counter's literal 14.

**Conflict:** the manager's MTS-08/MTS-10 Step 9 inclusion/reverse branch is not the same predicate.
